# MaxPersonalEffect - Мини-приложение для Max

Полнофункциональное приложение для продуктивности с бэкендом на FastAPI и фронтендом на чистом JavaScript.

## Структура проекта

```
├── backend/          # FastAPI бэкенд
│   ├── main.py       # Главный файл приложения
│   ├── database.py   # Работа с БД
│   ├── routers/      # API роутеры
│   └── requirements.txt
├── js/               # JavaScript файлы фронтенда
│   ├── api.js        # Модуль для работы с API
│   ├── todo.js       # Список дел
│   ├── goals.js      # Трекер целей
│   ├── habits.js     # Трекер привычек
│   ├── mood.js       # Трекер настроения
│   └── reports.js    # Отчёты
└── *.html            # HTML страницы

```

## Установка и запуск

### Локальная разработка

#### 1. Запуск бэкенда

```bash
cd backend
python -m pip install -r requirements.txt
python main.py
```

**Примечание для Windows:** Если команда `pip` не работает, используйте `python -m pip` вместо `pip`.

Бэкенд будет доступен по адресу: `http://localhost:8000`
Документация API: `http://localhost:8000/docs`

#### 2. Запуск фронтенда

Откройте `index.html` в браузере или используйте любой локальный сервер:

```bash
# Python
python -m http.server 8080

# Node.js
npx http-server -p 8080
```

Затем откройте в браузере: `http://localhost:8080`

### Деплой на Render.com

**Простой способ деплоя!** 🚀

1. Загрузите код на GitHub
2. Зайдите на [render.com](https://render.com)
3. Нажмите **New** → **Blueprint**
4. Подключите ваш репозиторий
5. Render автоматически создаст все сервисы из `render.yaml`

**Подробная инструкция:** См. файл [RENDER_DEPLOY.md](RENDER_DEPLOY.md)

### Запуск через Docker

**Локальный запуск с Docker Compose:**

```bash
docker-compose up -d
```

Приложение будет доступно:
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000

**Подробная инструкция:** См. файл [DOCKER.md](DOCKER.md)

### Бот для Max мессенджера

**Интеграция с мессенджером Max:**

```bash
cd bot
pip install -r requirements.txt
python main.py
```

Бот предоставляет:
- 🚀 Быстрый доступ к мини-приложению
- 📋 Просмотр списка дел прямо в мессенджере
- 📊 Отчетность за неделю

**Подробная инструкция:** См. файл [bot/README.md](bot/README.md)

## Функциональность

### ✅ Список дел
- Создание, редактирование, удаление задач
- Отметка выполнения
- Установка даты и времени напоминания

### ✅ Трекер целей
- Создание целей с подзадачами
- Отслеживание прогресса выполнения
- Разворачивание/сворачивание целей

### ✅ Трекер привычек
- Создание привычек
- Еженедельное отслеживание выполнения
- Водный трекер с настраиваемой целью

### ✅ Трекер настроения
- Оценка настроения (1-5)
- Выбор эмоций (до 20 вариантов)
- Календарь с историей настроения

### ✅ Отчёты и аналитика
- Статистика выполнения задач
- Графики настроения
- Прогресс по привычкам
- Еженедельные отчёты

## API Endpoints

Все API доступны по префиксу `/api/`:

- `/api/todos/` - Список дел
- `/api/goals/` - Трекер целей
- `/api/habits/` - Трекер привычек
- `/api/mood/` - Трекер настроения
- `/api/reports/` - Отчёты

Полная документация доступна в Swagger UI: `http://localhost:8000/docs`

## Технологии

- **Backend**: FastAPI, Gunicorn, Uvicorn
- **Frontend**: Vanilla JavaScript, HTML, CSS
- **База данных**: 
  - SQLite (локальная разработка)
  - PostgreSQL (продакшен на Render)

## Примечания

- Убедитесь, что бэкенд запущен перед использованием фронтенда
- CORS настроен для работы с локальным фронтендом
- Локально данные сохраняются в SQLite базу данных `max_personal_effect.db`
- На Render используется PostgreSQL (настраивается автоматически)
