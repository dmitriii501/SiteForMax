# Бот для Max мессенджера

Бот для интеграции MaxPersonalEffect с мессенджером Max.

## Функциональность

- 🚀 Открытие мини-приложения
- 📋 Просмотр списка дел (ближайшая задача, на сегодня, на неделю)
- 📊 Отчетность за неделю
- 🔄 Интеграция с API бэкенда

## Установка

```bash
cd bot
pip install -r requirements.txt
```

## Настройка

1. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

2. Убедитесь, что переменные окружения настроены:
- `BOT_TOKEN` - токен бота от Max
- `APP_URL` - URL мини-приложения
- `API_URL` - URL API бэкенда

## Запуск

```bash
python main.py
```

## Команды бота

- `/start` - Начать работу с ботом
- `/help` - Справка по командам
- `/app` - Открыть мини-приложение
- `/todos` - Посмотреть список дел
- `/report` - Отчетность за неделю

## Структура

```
bot/
├── main.py          # Основной файл бота
├── config.py        # Конфигурация
├── requirements.txt # Зависимости

```

## Деплой

Бот можно задеплоить на любой платформе, поддерживающей Python:
- Render.com
- Heroku
- Railway
- VPS сервер

Убедитесь, что переменные окружения настроены на платформе деплоя.
